# Shared human image library

Reusable character portraits for all games in this repository.

## Contract

- Path: `assets/humans/<person>/<emotion>.webp`
- Every person has exactly four images: `happy.webp`, `worried.webp`, `surprised.webp`, and `scared.webp`.
- Each game reads these assets by repository-relative path and must not add a separate copy of a person's portrait set.

## Available people

bat-hen, ben, daniel, eden, eliran, itzik, revital, rotem, samuel, shiran, and sophie.
