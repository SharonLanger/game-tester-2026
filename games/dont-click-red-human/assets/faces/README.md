# Human game face assets

This folder is reserved exclusively for `dont-click-red-human`.

Add one original face photo per participant here (an optional second image can be added later). Use short unique lowercase filenames such as `itzik.webp` or `shiran.webp`. Confirm each person's name before uploading. Color tints, mirroring, resizing, and misleading labels will be produced by the Human game; they do not require separate face images.

Images and this game are publicly accessible on GitHub Pages. The Human game is intentionally hidden only from the tester homepage; it is **not** private or password-protected.
